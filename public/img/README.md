
# Image Assets

This directory contains the image assets used throughout the application.

## Required Images

The following images need to be added manually:

1. `stone-bg.jpg` - Background image of Adrar stone for the hero section
2. `cta-bg.jpg` - Background image for call-to-action section
3. `subtle-pattern.png` - Subtle background pattern
4. `project1.jpg` through `project9.jpg` - Project thumbnail images
5. `pattern-1.png`, `pattern-2.png`, `pattern-3.png` - Decorative patterns for authentication page
6. `payments.png` - Payment methods icons for footer

These images should be added to match the design and aesthetic of the application.

Note: You can find appropriate images from stock photo websites or create custom graphics that match the theme of local Mauritanian materials and architecture.
